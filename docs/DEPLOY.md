# رفع قِرْش إلى GitHub وتثبيته على الجوال

كل الخطوات مجانية. التطبيق ملفات ثابتة فقط، وبياناتك تبقى على جوالك ولا تُرفع إلى أي مكان.

## الخطوة 1: رفع الكود إلى GitHub (مرة واحدة)

ستحتاج:
- الملف `qirsh-source.zip`. فيه الكود مع سجل التعديلات (مجلد `.git` المخفي).
- برنامج Git على الحاسوب: <https://git-scm.com/downloads>.

> لا تستخدم زر «Upload files» في موقع GitHub: المشروع فيه أكثر من 100 ملف، وهذا الزر لا يقبل أكثر من ذلك في المرة الواحدة، ولا يحفظ سجل التعديلات.

1. تأكد أن المستودع `Qirshy` **فارغ** على GitHub. إن كان فيه ملف README أُنشئ تلقائياً، انظر الملاحظة في آخر هذه الخطوة.
2. فُك ضغط `qirsh-source.zip`، فيظهر مجلد `qirsh`.
3. افتح الطرفية داخل المجلد:
   - **Windows:** انقر بالزر الأيمن داخل المجلد ثم «Open Git Bash here».
   - **Mac:** اسحب المجلد إلى برنامج Terminal بعد كتابة `cd ` (مع مسافة).
4. اكتب الأوامر التالية سطراً سطراً:

```bash
git remote add origin https://github.com/asmahmedsakalla2003new-cloud/Qirshy.git
git push -u origin main
```

5. عند أول رفع يطلب Git تسجيل الدخول إلى GitHub: اختر الدخول عبر المتصفح.
6. افتح صفحة المستودع: يجب أن ترى المجلدات `src` و`docs` وملف `README.md`.

**إن كان في المستودع ملف README مسبقاً**، يرفض GitHub الرفع. في هذه الحالة اكتب:

```bash
git pull origin main --allow-unrelated-histories --no-edit
git push -u origin main
```

إن ظهر تعارض في `README.md`، احتفظ بنسخة المشروع. أو احذف الملف من موقع GitHub أولاً ثم أعد الرفع.

**بديل دون أوامر:** برنامج GitHub Desktop (<https://desktop.github.com>):
1. File ← Add local repository، واختر مجلد `qirsh`.
2. Publish repository، أو Push إن كان المستودع موجوداً.

## الخطوة 2: نشر التطبيق على رابط https (مرة واحدة)

الجوال يحتاج رابط `https` ليثبّت التطبيق ويشغّله دون إنترنت. أنصح بـ **Netlify**: مجاني، ويعمل مع المستودع الخاص أو العام، وكل إعداداته جاهزة في ملف `netlify.toml`.

1. ادخل <https://app.netlify.com> وسجّل الدخول بحساب GitHub.
2. اضغط **Add new project** ← **Import an existing project** ← **GitHub**.
3. اسمح لـ Netlify بالوصول إلى المستودع `Qirshy` فقط، ثم اختره.
4. ستجد الإعدادات معبّأة من الملف. تأكد منها:
   - Build command: `npm run build`
   - Publish directory: `dist`
5. اضغط **Deploy**، وانتظر دقيقتين تقريباً حتى تظهر الحالة **Published**.
6. ستحصل على رابط مثل `https://qirsh-xxxx.netlify.app`. يمكنك تغيير الاسم من Site configuration ← Change site name، فيصير مثلاً `https://qirshy.netlify.app`.

**التحديثات لاحقاً:** كل رفع جديد إلى GitHub يعيد Netlify نشره تلقائياً. التطبيق على الجوال يأخذ النسخة الجديدة عند فتحه التالي، وبياناتك لا تتأثر.

**بديل أسرع دون GitHub:**
1. افتح <https://app.netlify.com/drop>.
2. اسحب مجلد النسخة الجاهزة إليها (من `qirsh-build.zip` بعد فك الضغط).
3. لكن التحديث في هذه الطريقة يدوي: تعيد السحب بعد كل تعديل.

**بديل آخر:** Cloudflare Pages. أنشئ مشروعاً من المستودع، واختر Framework preset: Vite، وBuild command: `npm run build`، وOutput: `dist`. ملف `.nvmrc` يحدد نسخة Node تلقائياً.

> لماذا لا GitHub Pages؟ يضع التطبيق تحت مسار فرعي (`/Qirshy/`)، فلا يعمل التثبيت والعمل دون إنترنت دون تعديلات في الكود. ويتطلب أن يكون المستودع عاماً في الخطة المجانية.

## الخطوة 3: التثبيت على الجوال

### Android (Chrome)
1. افتح الرابط في **Chrome**.
2. انتظر حتى تظهر الشاشة الترحيبية، ثم اضغط «ابدأ الآن».
3. من القائمة (⋮) اختر **«تثبيت التطبيق»** أو **«إضافة إلى الشاشة الرئيسية»**، ثم «تثبيت».
4. تظهر أيقونة «قِرْش» بين التطبيقات، ويفتح بشاشة كاملة مثل أي تطبيق.

### iPhone (Safari)
1. افتح الرابط في **Safari**. التثبيت على iPhone يعمل من Safari فقط.
2. اضغط زر المشاركة (المربع والسهم) ← **«إضافة إلى الشاشة الرئيسية»** ← «إضافة».
3. افتح التطبيق من الأيقونة، **وليس من Safari**.

> **مهم على iPhone:** ثبّت التطبيق **قبل** إدخال بيانات حقيقية، واستخدمه من الأيقونة. قد يحذف Safari بيانات المواقع غير المثبّتة بعد أيام من عدم الاستخدام.

### بعد التثبيت
- افتح التطبيق مرة وأنت متصل بالإنترنت، وبعدها يعمل دون إنترنت.
- قراءة الفواتير تحتاج إنترنت في أول استخدام فقط لتنزيل الأداة (حوالي 9 ميغابايت).
- **انسخ بياناتك احتياطياً** بانتظام: الإعدادات ← النسخ الاحتياطي ← «إنشاء نسخة احتياطية»، واحفظ الملف في مكان آمن. حذف التطبيق أو مسح بيانات المتصفح يحذف البيانات، والنسخة الاحتياطية هي الطريقة الوحيدة لاستعادتها.
- **للانتقال إلى جوال جديد:** أنشئ نسخة احتياطية في القديم، وثبّت التطبيق في الجديد، ثم «استعادة» من الملف.

## للمطوّر: تشغيل المشروع على الحاسوب

يحتاج Node.js 22 أو أحدث. الأوامر في [`README.md`](../README.md):

```bash
npm install
npm run dev
```
