# قِرْش (Qirsh)

تطبيق ويب عربي (PWA) لإدارة المصاريف والميزانيات بالشيكل والدولار. مجاني بالكامل، ويعمل دون إنترنت، ويحفظ البيانات على جهاز المستخدم فقط.

- الخطة التنفيذية: [`QIRSH_CLAUDE_CODE_PLAN.md`](QIRSH_CLAUDE_CODE_PLAN.md)
- سجل القرارات: [`DECISIONS.md`](DECISIONS.md)

## المتطلبات

- Node.js 22 أو أحدث

## الأوامر

| الأمر | الوظيفة |
|-------|---------|
| `npm install` | تثبيت الاعتماديات |
| `npm run dev` | تشغيل نسخة التطوير على `http://localhost:5173` (لا يعمل فيها وضع دون إنترنت) |
| `npm run build` | فحص الأنواع ثم بناء نسخة الإنتاج في `dist/` |
| `npm run preview` | تشغيل نسخة الإنتاج محلياً على `http://localhost:4173` (يعمل فيها وضع دون إنترنت) |
| `npm test` | اختبارات الوحدات (Vitest) |
| `npm run test:e2e` | اختبارات المتصفح (Playwright): RTL، التنقل، العمل دون إنترنت، ملف manifest |
| `npm run lint` | فحص الكود (oxlint) |
| `npm run icons` | إعادة توليد أيقونات PWA من الشعار |
| `npm run ocr-assets` | نسخ ملفات أداة قراءة الفواتير إلى `public/ocr` (يعمل تلقائياً قبل `dev` و`build`) |

## بنية المجلدات

```
src/
  app/          # هيكل التطبيق: التنقل، شاشة البداية، المسارات
  components/   # عناصر الواجهة المشتركة: أزرار، حقول، بطاقات، رسائل
  core/         # نظام التصميم (theme/)
  domain/       # منطق الأعمال بلا واجهة: المال، التواريخ، الحسابات، العمليات، الفئات، الميزانيات، التحويلات، الديون، التقارير وCSV، صيغة النسخة الاحتياطية (قابل للاختبار)
  data/         # قاعدة البيانات المحلية (Dexie/IndexedDB) والمستودعات
  features/     # شاشات كل ميزة
tests/e2e/      # اختبارات المتصفح
docs/           # أدلة: تجربة التطبيق على الهاتف
scripts/        # أدوات مساعدة (توليد الأيقونات، نسخ ملفات قراءة الفواتير)
```

## البيانات

كل البيانات في قاعدة IndexedDB باسم `qirsh` داخل متصفح المستخدم، ولا تُرسل إلى أي خادم. المبالغ تُخزَّن أعداداً صحيحة بالأغورة/السنت. لتغيير بنية القاعدة أضف إصداراً جديداً في `src/data/db.ts`، ولا تعدّل إصداراً منشوراً.

## النسخ الاحتياطي

من الإعدادات ← «النسخ الاحتياطي والاستعادة». الملف JSON واحد بكل البيانات وبصمة SHA-256 (التفاصيل في `src/domain/backup.ts` و`DECISIONS.md`). عند إضافة إصدار جديد لقاعدة البيانات أضف أي جدول جديد إلى `BACKUP_TABLES` وإلى التحقق في `validateData`.

## قراءة الفواتير

تتم القراءة على الجهاز بمكتبة Tesseract.js، والصورة لا تُرسل إلى أي مكان. ملفات الأداة (محرك WebAssembly وبيانات اللغتين العربية والإنجليزية) تُنسخ من `node_modules` إلى `public/ocr/`. هذا المجلد غير محفوظ في المستودع ويُعاد إنشاؤه عند كل `dev` أو `build`. تُنزَّل الملفات عند أول قراءة فقط، ثم يحفظها Service Worker. منطق استخراج المبلغ والتاريخ في `src/domain/receipt.ts`، وله اختبارات.

## النشر

الناتج في `dist/` ملفات ثابتة فقط، ولا يحتاج خادماً أو قاعدة بيانات. يمكن نشره على أي استضافة مجانية للملفات الثابتة تدعم HTTPS. الملف `public/_redirects` يوجّه كل المسارات إلى `index.html` (يدعمه Netlify وCloudflare Pages). خطوات النشر والتجربة على الهاتف في [`docs/PHONE_TESTING.md`](docs/PHONE_TESTING.md).
